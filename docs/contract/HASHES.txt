REPRODUCING THESE DIGESTS
----------------------------------------------------
Digests are over the exact bytes of the files as committed. The
repository sets `* -text` in .gitattributes, disabling end-of-line
conversion, so a clone on any platform yields the same bytes and the
same digests. Verify with:  sha256sum <file>
